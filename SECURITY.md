# Security

Do not post credentials, private recordings or personal data in issues. For a suspected security issue, use GitHub's private vulnerability reporting if it is enabled for this repository. If it is unavailable, open a minimal issue asking for a private contact route without disclosing exploit details.

SongWave uses undocumented macOS hardware interfaces. The preview has not been audited, notarized or certified safe for continuous actuator use. See [Privacy](PRIVACY.md) for data handling and [release status](docs/releasing.md) for distribution limits.
