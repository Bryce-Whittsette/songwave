The model separates vocal and accompaniment masks. Model inference and signal
processing run locally. No account, runtime download, Python, or network service
is needed. SongWave loads it only while Isolated vocal rendering is selected.

The native adapter is based on swift-spleeter's Core ML and Accelerate backends.
