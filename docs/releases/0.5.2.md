# SongWave 0.5.2 — First public preview

Public Preview · November 25, 2026

The first public SongWave release: feel music already playing on your Mac through its Force Touch trackpad.

**[Download this version](https://github.com/Bryce-Whittsette/songwave/releases/download/v0.5.2/SongWave-0.5.2-AppleSilicon.dmg)** · [Current version and installation](https://github.com/Bryce-Whittsette/songwave#install) · [Version history](https://github.com/Bryce-Whittsette/songwave/blob/main/CHANGELOG.md)

## What arrived

- **Automatic Mac Audio:** open SongWave and play music normally in Spotify, Apple Music, or a browser. No song link or file is required.
- **Speakers + haptics:** hear the song normally and feel detected rhythmic taps.
- **Trackpad only:** follow vocals using the lighter **Light** mode or the bundled, on-device **Isolated** mode. Isolated uses more memory and about 0.8 seconds of buffering, with a brief first-use warmup.
- **Personal tuning:** trackpad EQ, genre starting points, intensity, timing adjustment, and optional Mac volume following. Point at Intensity or an EQ value and swipe with two fingers; click the number to open precise controls.
- **Everyday controls:** a menu-bar toggle, saved listening setup and output mode, and automatic listening on launch.
- **Extras:** optional keyboard-light pulses, a 45-second Insane Ultra burst with a cooldown, and optional authored AHAP patterns for local files. The demo plays only when explicitly selected.
- **Music filtering:** on-device recognition, recognized-call suppression, and an optional Chrome/Firefox YouTube category filter. Audio-only filtering can mistake instrumental video intros for music.

## Install this version

1. Download and open **SongWave-0.5.2-AppleSilicon.dmg**.
2. Drag **SongWave** into **Applications**, then open it from Applications.
3. Complete setup and allow **System Audio Recording**. Play music and rest a finger lightly on the trackpad.

Requires **Apple silicon, macOS 14.2 or later, and a Force Touch trackpad**. Tested on an M4 MacBook Air. This preview has **not been notarized by Apple**. If macOS blocks it, see [SongWave's installation help](https://github.com/Bryce-Whittsette/songwave/blob/main/docs/troubleshooting.md#macos-wont-open-the-app).

**Choose the DMG** for normal installation. **SongWave-macOS.zip** contains the same app. **songwave-source.zip / Source code** is for building or reading the code; **SHA256SUMS** contains download checksums.

## Known limits at release

Music recognition and vocal separation are approximate. Some protected streams cannot be captured. Ad hoc preview updates can trigger new macOS permission prompts. Trackpad and keyboard features use undocumented interfaces and can vary across hardware and OS versions. Ultra's timer and cooldown are software limits, not a manufacturer safety rating. This version does not include the separate Bass sustain layer added in 0.5.3.

<details>
<summary>Developer notes: the original public baseline</summary>

- Native SwiftUI app, with Liquid Glass on macOS 26 and later and system light/dark appearance support.
- Per-process Core Audio taps copy PCM into bounded memory. Analysis and output scheduling run away from the UI thread; no virtual audio driver is required.
- Accelerate FFTs, positive spectral flux, harmonic rejection, and adaptive mid/treble thresholds generate percussion events. Host-time attack/release envelopes shape output. Core Audio output latency is an estimate, with a manual timing offset available.
- Light vocal focus uses a causal harmonic tracker. Isolated loads a bundled two-stem Spleeter Core ML model only when selected. Its buffering and first-use warmup differ from the speaker-mode DSP path.
- AHAP 1.0 haptic events and parameter curves can override automatic percussion for a local file. Embedded audio events are skipped, referenced audio paths are not opened, and parsing/output bounds are enforced. Apple's Music Haptics catalog is not integrated.
- Trackpad output uses the undocumented MultitouchSupport actuator interface; keyboard lighting uses CoreBrightness when available. Software duration, intensity, cooldown, and thermal-state guards do not measure actuator temperature or certify hardware endurance.
- Source, model, and third-party licensing are documented in the repository. The GitHub release includes a DMG, app ZIP, tracked-source ZIP, and SHA-256 checksums. Automated macOS checks cover offline regressions and app building; they cannot validate physical feel on every Mac.
