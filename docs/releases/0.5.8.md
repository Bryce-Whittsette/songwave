# SongWave 0.5.8 — Energy and detail

Public Preview · November 27, 2026 · build 18

Choose **SongWave → Check for Updates…** and approve the update. [Download for Mac](https://github.com/Bryce-Whittsette/songwave/releases/download/v0.5.8/SongWave-0.5.8-AppleSilicon.dmg).

## What changed

- **Feel → Both** blends vocal texture with bass and percussion in either output. It shares one FFT and uses Light analysis; the saved Isolated choice remains available for Voice → Trackpad only.

- Hidden and inactive player windows stop visual waveform updates and animations. Music analysis and haptic output continue independently.
- Messages sharing-service discovery is cached instead of repeated during player updates.
- **Fine Tune → Detail balance** lifts detected mid/treble taps against bass rumble. It shapes existing hits; it does not detect new events or remove all vocal leakage.
- **Trackpad only** uses manual intensity even when Mac speaker volume is muted. Follow Mac volume remains available for Speakers + haptics.
- A standalone **iPhone source prototype** adds file playback with Light Voice/Beat/Both haptics and Apple Music playback with Apple's available haptic tracks. No iPhone download is available yet.

The existing AI isolation model and weights are unchanged. No new model is downloaded. [Energy work and measurement limits](../energy.md) · [iPhone supported sources and remaining work](../mobile.md).

<summary>Developer notes</summary>

The visual subscriber retains the latest packet while paused and rejects stale packets on resume. Visibility uses window/app notifications; the audio and motor scheduler cadence is unchanged. Tests deliver 10,000 hidden packets with zero visual publications and cover resume, silence and cancelled releases.

Detail balance stores a bounded preset value with a migration default of 0.35. Detected sharp accents gain up to 70%, with temporary rumble reduction beneath them; output limits, timing, Voice passthrough and suppression remain tested. Ultra applies its own value to a copy of tuning.

The iPhone target shares Light DSP, bounds its recent PCM queue and stops analysis when hidden, paused, unsupported or at zero intensity. Generic Simulator/device builds and host-side queue/policy tests pass. Physical haptics, MusicKit authorization/playback, background behavior, VoiceOver and energy require device testing. The iPhone build is unsigned and is not ready for public distribution.

No controlled before/after battery or physical response measurement has been completed for this release. The public macOS preview remains unnotarized.
