# SongWave 0.5.4 — Launch preparation

Development candidate. The public download remains 0.5.3 while this build is reviewed.

## What changed

- **Visible Settings:** a labeled button and Command-comma open General, Playback Access, Effects, Updates and Help. Everyday keyboard/volume toggles stay visible in the player.
- **Interface refinement:** clearer SF Pro hierarchy, stronger content contrast, native glass controls, consistent spacing and a clearer listening/haptics distinction.
- **Precision editing:** numeric fields focus on open and explain invalid entries without dismissing them.

- **In-app updates:** automatic checks with approval before installation. Signed release information and downloads; a manual check in the SongWave menu and Settings → Updates.
- **Calls when using song links:** explicit Spotify/Music routes pause for recognized active calls, release capture, and reconnect afterward. An idle FaceTime app does not pause music.
- **Smoother bypass:** switching speaker-mode haptics off uses a short fade. Stop, recognized calls and capture errors still stop output immediately.
- **Access recovery:** saved setup and the latest audio-access check are separate. Failed checks offer Retry and prevent automatic continuation until a successful check.
- **Tuning help:** Transient emphasis explains what higher settings feel like.
- **Pattern validation:** AHAP numeric fields reject Boolean values.

People on 0.5.3 need one manual installation of the first updater-enabled release. Later signed releases can arrive through the app. An ordinary code push does not publish an update.

<summary>Developer notes</summary>

Sparkle 2.10.1 is pinned by SHA-256. The app requires signed feeds and verifies archives before extraction. Automatic downloading/installation and system profiling are disabled. The per-app private key stays in the maintainer's Keychain; feed publication uses public-key verification and no private CI secret.

Shared call policy covers automatic Mac Audio and explicit player routes. A host-time bypass ramp is separate from immediate interruption/cleanup. New offline tests cover four provider/mode combinations, call release/reconnect, failures, muting restoration, fade cadence and access recovery. Stress testing also covered malformed links/patterns, concurrent ring-buffer pressure, extreme PCM and 20 minutes of synthetic analysis. These do not establish physical latency, whole-app RAM or multi-Mac compatibility.
