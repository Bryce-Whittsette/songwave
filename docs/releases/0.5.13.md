# SongWave 0.5.13 — Grouped listening tools

Public Preview · November 27, 2026 · build 23

Choose **SongWave → Check for Updates…** and approve the update. [Download for Mac](https://github.com/Bryce-Whittsette/songwave/releases/download/v0.5.13/SongWave-0.5.13-AppleSilicon.dmg).

## What changed

- **Three clear tool categories:** Sound holds genre, vocal choices, volume following and Fine Tune. Trackpad EQ has its own page. Experiments groups keyboard light, Insane Ultra and local-file patterns.
- **Labeled fine tuning:** applicable controls sit under Beat, Voice and Timing headings. Bass, Mid and Treble remain grouped in Band Settings, with scrolling for compact windows.
- **Focused listening:** Play/Stop, Output, Feel and Intensity stay in the main player. Ultra still requires its existing warning and confirmation; the main Stop Ultra action remains available during a run.

This changes layout, grouping and accessibility labels. Isolation, audio analysis, haptic rendering, genre values, timing controls, Ultra limits and saved settings behavior are unchanged. The native monochrome appearance is retained. This public preview remains unnotarized; the iPhone prototype has no public download.

<summary>Developer notes and validation</summary>

A native segmented category picker scopes Tools to one content group at a time. Its selection is local view state, retained while the player is open, and does not change tuning. Switching categories restores the scroll position to the top. Fine Tune composes the same controls and bindings in Beat, Voice and Timing sections; its existing focus/output conditions, ranges and reset action remain intact. EQ Band Settings exposes native heading traits and uses bounded scrolling. No model, timer, analyzer or motor command is added.

The native fixture covers category separation, labels/actions, heading order, reachable controls, retained EQ/genre/intensity, and opening/canceling Ultra without starting playback. It exercises light/dark and normal/reduced-motion category states, plus Beat/Voice/Both in both output modes. Existing setup/recovery, visual-listening, DSP, update verification and iPhone compilation checks remain in CI. The fixture uses fake audio/trackpad edges and deterministic preferences; it never changes the listener's real settings or actuates hardware.
