# SongWave 0.5.7 — Voice and Beat

Public Preview · November 26, 2026

Choose **SongWave → Check for Updates…** and approve the update. [Download for Mac](https://github.com/Bryce-Whittsette/songwave/releases/download/v0.5.7/SongWave-0.5.7-AppleSilicon.dmg).

## What changed

- **Feel → Voice / Beat:** choose vocal pitch and texture or bass and percussion in either output mode. The focus stays selected when changing output. Custom file patterns keep their authored content.
- **Quiet details:** Beat uses a lower silence gate so soft percussion can be detected when the mix becomes quiet. Voice keeps its previous gate.
- **Voice timing:** speaker-mode timing compensation accounts for Voice's larger analysis window.
- **Documentation:** README explains the choices and the accessibility design goal, including the need for Deaf and hard-of-hearing user feedback.

The AI isolation model, inference code and weights are unchanged. **Isolated** remains available only for Voice with Trackpad only, with roughly 0.8 seconds of buffering. Beat and Voice with speakers use Light analysis. No new model or cloud audio service was added.

Dense, articulated vocals can still hide some percussion. Requested tactile frequencies are not physical motor measurements. This release does not claim full-song accuracy or solve every report of bass-dominated feedback. This preview is not notarized.
