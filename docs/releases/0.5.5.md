# SongWave 0.5.5 — Ultra response

Public Preview · November 26, 2026

[Download for Mac](https://github.com/Bryce-Whittsette/songwave/releases/download/v0.5.5/SongWave-0.5.5-AppleSilicon.dmg). Already on 0.5.4? Choose **SongWave → Check for Updates…** and approve the update.

## What changed

- **A distinct Ultra response:** a temporary processing profile boosts bass and percussion texture, sharpens attacks, and lifts detected accents toward the existing output ceiling.
- **Your EQ stays yours:** Ultra ignores the saved EQ and intensity while active. Displayed knobs and saved preferences stay unchanged; normal processing resumes at the end or when stopped.
- **Beat lighting and color:** stronger keyboard accents on detected beats, plus an Ultra border around the signal monitor.

Ultra still follows the current source; starting it does not play the demo. The burst lasts 45 seconds with a cooldown. Silence, recognized-call suppression, haptic bypass, thermal stops and optional Mac-volume following remain effective. Strong effects can increase heat and wear; the timer is not a manufacturer safety rating. Physical strength depends on the Mac and song. This preview is not notarized.

<summary>Developer notes</summary>

The old speaker path multiplied the ordinary response by 0.83, making Ultra potentially weaker than normal at full user intensity. The new bounded response curve lifts smaller detected levels with a maximum of 0.83. It adds no lookahead, model or audio buffer. A value-copy tuning override is applied inside Session.tick, retaining the user's timing calibration and vocal isolation choice. No Studio setting or UserDefaults EQ value is changed. Trackpad-only duty gating remains.

Regression tests cover copy isolation/restoration, timing preservation, a monotonic bounded response across 1,001 levels, and silence/nonfinite rejection. Existing DSP and lifecycle checks cover suppression and cleanup. These checks do not establish tactile strength on every Mac or long-term motor safety.
